# Alexi — Professional Content Writer Landing Page

A clean, responsive, single-page landing page for a freelance content writing service. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no dependencies.

## ✨ Features

- **Hero section** with animated gradient blobs, headline, and dual CTAs
- **About section** with bio, skills list, and a featured quote card
- **Services section** — 4 service cards with custom SVG icons (Blog Writing, Web Copy, SEO Content, Social Media Copy)
- **Testimonials** — 2 client quotes with star ratings and avatars
- **Contact form** with full client-side validation (name, email, message) and success message
- **Mailto link** for direct email contact
- **Footer** with social media icons (LinkedIn, Twitter/X, Instagram, Email) and back-to-top button
- **Mobile hamburger menu** with slide-in drawer
- **Scroll reveal animations** via IntersectionObserver
- **Accessibility**: semantic HTML, skip link, ARIA labels, keyboard navigation, focus-visible outlines, reduced-motion support
- **Performance**: system fonts fallback, preconnect for Google Fonts, no JS frameworks, minimal footprint

## 🎨 Design

- **Typography**: Fraunces (display serif) + Outfit (body sans-serif)
- **Palette**: warm cream background, deep ink text, coral accent
- **Aesthetic**: editorial / literary — befitting a content writer
